# jshERP前端优化改进建议

## 1. 代码组织结构优化

### 1.1 目录结构优化
- **问题**：当前目录结构较为复杂，组件和页面混合在一起
- **建议**：
  - 按照功能模块重新组织目录结构
  - 分离业务组件和通用组件
  - 建立清晰的文件命名规范

**优化示例**：
```
src/
├── components/           # 通用组件
│   ├── common/          # 基础通用组件
│   ├── business/        # 业务通用组件
│   └── layout/          # 布局组件
├── views/               # 页面
│   ├── system/          # 系统管理
│   ├── material/        # 物料管理
│   ├── bill/            # 单据管理
│   ├── financial/       # 财务管理
│   └── report/          # 报表管理
├── api/                 # API请求
│   ├── modules/         # 按模块分类API
│   └── index.js         # API导出
├── utils/               # 工具函数
│   ├── auth/            # 权限相关
│   ├── http/            # HTTP相关
│   └── common/          # 通用工具
└── store/               # 状态管理
    ├── modules/         # 按模块分类store
    └── index.js         # store导出
```

### 1.2 代码拆分优化
- **问题**：部分组件和页面代码过于冗长
- **建议**：
  - 将复杂组件拆分为多个子组件
  - 提取重复逻辑为公共函数
  - 使用组合式API（如果升级到Vue 3）

**优化示例**：
```vue
<!-- 优化前 -->
<template>
  <div class="complex-component">
    <!-- 大量模板代码 -->
  </div>
</template>
<script>
export default {
  data() {
    return {
      // 大量数据
    }
  },
  methods: {
    // 大量方法
  }
}
</script>

<!-- 优化后 -->
<template>
  <div class="complex-component">
    <sub-component-1 :data="data1" />
    <sub-component-2 :data="data2" />
  </div>
</template>
<script>
import SubComponent1 from './SubComponent1.vue'
import SubComponent2 from './SubComponent2.vue'

export default {
  components: {
    SubComponent1,
    SubComponent2
  },
  data() {
    return {
      data1: {},
      data2: {}
    }
  }
}
</script>
```

### 3.3 网络请求优化
- **问题**：重复请求和请求处理不当
- **建议**：
  - 实现请求防抖和节流
  - 添加请求缓存
  - 优化请求错误处理

**优化示例**：
```js
// 请求防抖
function debounce(func, wait) {
  let timeout
  return function() {
    clearTimeout(timeout)
    timeout = setTimeout(() => {
      func.apply(this, arguments)
    }, wait)
  }
}

// 请求缓存
const requestCache = new Map()
async function requestWithCache(url, params) {
  const key = `${url}_${JSON.stringify(params)}`
  if (requestCache.has(key)) {
    return requestCache.get(key)
  }
  const result = await axios.get(url, { params })
  requestCache.set(key, result)
  return result
}
```

### 4.3 CSRF防护
- **问题**：缺少CSRF防护机制
- **建议**：
  - 实现CSRF token机制
  - 在请求头中添加CSRF token

**优化示例**：
```js
// axios请求拦截器
axios.interceptors.request.use(config => {
  const token = Vue.ls.get(ACCESS_TOKEN)
  const csrfToken = Vue.ls.get(CSRF_TOKEN)
  if (token) {
    config.headers['X-Access-Token'] = token
  }
  if (csrfToken) {
    config.headers['X-CSRF-Token'] = csrfToken
  }
  return config
})
```

### 4.4 敏感信息存储
- **问题**：敏感信息未加密存储
- **建议**：
  - 加密存储敏感信息
  - 使用sessionStorage替代localStorage存储敏感信息
  - 实现自动清理机制

**优化示例**：
```js
// 加密存储
function encryptData(data) {
  // 简单的加密实现
  return btoa(encodeURIComponent(JSON.stringify(data)))
}

function decryptData(encryptedData) {
  // 简单的解密实现
  return JSON.parse(decodeURIComponent(atob(encryptedData)))
}

// 存储token
Vue.ls.set(ACCESS_TOKEN, encryptData(token), 7 * 24 * 60 * 60 * 1000)

// 读取token
const token = decryptData(Vue.ls.get(ACCESS_TOKEN))
```

## 5. 功能优化

### 5.1 权限控制优化
- **问题**：权限控制逻辑较为复杂
- **建议**：
  - 简化权限控制逻辑
  - 优化权限检查性能
  - 实现权限缓存机制

**优化示例**：
```js
// 优化权限检查函数
export function checkPermission(permission) {
  // 缓存权限列表
  if (!window.permissionCache) {
    window.permissionCache = JSON.parse(sessionStorage.getItem(USER_AUTH) || "[]")
  }
  
  return window.permissionCache.some(item => 
    item.type !== '2' && item.action === permission
  )
}

// 简化v-has指令
Vue.directive('has', {
  inserted: (el, binding) => {
    if (!checkPermission(binding.value)) {
      el.parentNode.removeChild(el)
    }
  }
})
```

### 5.2 错误处理优化
- **问题**：错误处理机制不够完善
- **建议**：
  - 实现全局错误处理
  - 统一错误提示格式
  - 记录错误日志

**优化示例**：
```js
// 全局错误处理
Vue.config.errorHandler = function(err, vm, info) {
  console.error('Vue错误:', err)
  console.error('错误信息:', info)
  // 发送错误日志到服务器
  logError(err, info)
}

// 统一错误提示
function showError(message) {
  notification.error({
    message: '系统提示',
    description: message,
    duration: 4
  })
}

// 错误日志记录
function logError(err, info) {
  axios.post('/api/log/error', {
    error: err.message,
    stack: err.stack,
    info: info,
    url: window.location.href
  })
}
```

### 5.3 用户体验优化
- **问题**：部分操作响应较慢，用户体验不佳
- **建议**：
  - 添加加载状态提示
  - 优化表单验证
  - 实现批量操作

**优化示例**：
```vue
<template>
  <div>
    <a-button 
      type="primary" 
      @click="handleSubmit" 
      :loading="loading"
    >
      提交
    </a-button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      loading: false
    }
  },
  methods: {
    async handleSubmit() {
      this.loading = true
      try {
        await this.submitForm()
        notification.success({ message: '操作成功' })
      } catch (error) {
        showError('操作失败')
      } finally {
        this.loading = false
      }
    }
  }
}
</script>
```
